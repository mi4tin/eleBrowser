## 划线功能调研

### 版本一：构思阶段（适合尚未开发，寻求反馈）

**标题/首行：** 准备做个「可上云」的本地划线浏览器，想听听大伙的意见 🧐

**正文：**

把市面上的划线工具都试了一圈，问题还挺集中的：

- Diigo 太老了，UI 像上个时代的产物
- LINER 国内访问慢，免费版限制多
- 简悦功能全但配置复杂，学习成本高
- 五彩数据强制在云端，隐私有点不放心

于是决定自己写一个，定位是 **「数据主权在你手里」** 的划线浏览器，核心逻辑是 **“本地优先，上云可选”**。

**初期方案是这样的：**
- **本地优先 🔒**：所有划线、笔记、高亮数据默认存本地（SQLite + IndexedDB）。不上云也能完整体验，离线可用，响应快。
- **可选的云同步 ☁️**：底层数据模型设计好，**为以后的跨端同步预留接口**。等时机成熟（比如出了移动端），用户可以自己选择是否开启云同步。开启后，云端只负责存储和同步，不会拿着你的数据做别的。
- **数据可迁移**：无论是本地还是云端，数据都支持导出为标准格式（Markdown / JSON / CSV），方便你随时迁到 Obsidian、Notion。

**技术栈：**
- 客户端：Electron + Vue3 + TypeScript
- 本地存储：SQLite + IndexedDB
- （未来的云服务端：Golang + PostgreSQL + Redis）

**想问问大家：**
1.  你们平时会用网页划线/标注工具吗？主要是读技术文档、看论文，还是收集资料？
2.  现有工具最让你抓狂的痛点是什么？
3.  “数据默认在本地，可自己选择是否同步到云端”这个设计，对你们来说是加分项吗？
4.  如果有一天上云，你们能接受怎样的付费模式？（比如按存储空间大小订阅）

目前已经在写了，过两周出第一个内测版（Win + Mac）。感兴趣的评论区扣 1，或者留个邮箱，到时候挨个通知 🙋‍♂️

## 版本二：轻调研版（不对比竞品，纯试探需求）

**想做一个网页划线浏览器，你平时会用吗？**

最近在琢磨做一个网页划线浏览器，大概想法是这样的：划线笔记都存你自己电脑上，不上网也能正常用；以后想做手机版的话，你可以自己决定要不要云同步；数据支持导出。

目前还在想怎么做好，想先问问你：你平时会在网页上划线做笔记的需求吗？一般在什么场景下用，是看技术文档、读论文，还是收集资料？你觉得一个好用的划线工具最重要的是什么，是流畅顺手、数据安全、能跨设备同步，还是有别的更看重的点？

如果已有在用的划线工具，可以简单说说，最让你满意的地方，还有你觉得可以改进的地方。
