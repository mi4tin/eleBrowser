1、上层WebContentsView，可以设置透明，看到下层，但是不能操作下层。这就像在一块完全透明的玻璃上操作，手指触碰到的始终是玻璃，而不是它下面的物体。

2、contextIsolation: true 时的注意事项：
   - DOM 事件监听有效：addEventListener、document、window 等 DOM API 是跨上下文共享的
   - 直接重写 window.alert/confirm/prompt 无效：preload 的 window 和页面的 window 是隔离的
   - 直接重写 XMLHttpRequest/fetch 无效：同上，不会影响到页面
   - 正确做法：通过注入 <script> 标签到页面上下文，配合 window.postMessage 实现通信
