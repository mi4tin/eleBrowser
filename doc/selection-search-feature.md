# 选中文本搜索功能使用说明

## 功能介绍
eleBrowser 浏览器新增了智能文本选择搜索功能。当您选中页面上的文本并按下 `Ctrl+F` 快捷键时，选中的内容会自动填充到搜索框中并立即开始搜索。

## 使用方法

### 基本操作
1. 在网页中选中您想要搜索的文本
2. 按下 `Ctrl+F`（Windows/Linux）或 `Cmd+F`（Mac）
3. 搜索面板会自动打开，选中的文本已填充到搜索框中
4. 搜索会自动开始，匹配的结果会在页面中高亮显示

### 示例场景
- 选中文章中的关键词，快速在整个页面中查找该词的所有出现位置
- 选中产品名称，立即搜索相关信息
- 选中技术术语，快速定位相关内容

## 功能特点
- ✅ **智能检测**：自动识别是否有文本被选中
- ✅ **无缝集成**：与现有搜索功能完全兼容
- ✅ **即时搜索**：选中文本后立即开始搜索，无需额外操作
- ✅ **保持原有功能**：没有选中文本时仍可正常使用搜索功能

## 注意事项
- 此功能仅在按下 `Ctrl+F` 快捷键时生效
- 右键菜单中的"在页面中搜索选中文本"功能不受影响
- 搜索面板的其他操作（F3导航、ESC关闭等）保持不变

## 技术实现
该功能通过以下技术实现：
1. 监听 `Ctrl+F` 快捷键事件
2. 使用 `window.getSelection()` 获取当前选中文本
3. 通过 Electron IPC 机制将文本传递给搜索面板
4. 自动触发搜索操作并显示结果
