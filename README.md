## 项目介绍
这是一个浏览器，具有常用的浏览器功能。

## 开发相关

### 安装依赖
使用 **pnpm** 命令安装依赖：
```bash
pnpm install
```

### 运行项目
```bash
pnpm start
```

### 打包项目

#### 打包所有平台
```bash
pnpm dist
```

#### 打包 Windows 版本
```bash
pnpm dist:win
```

#### 打包 Mac 版本
```bash
pnpm dist:mac
```

#### 打包 Linux 版本
```bash
pnpm dist:linux
```

#### 构建并打包到目录（不打包成安装包）
```bash
pnpm build:unpack
```
