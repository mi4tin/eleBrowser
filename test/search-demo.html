🔍 网页内文本搜索功能演示

功能说明

此页面用于演示和测试网页内文本查找功能。请使用 Ctrl+F 快捷键打开搜索面板。

搜索面板将显示：当前匹配项/总匹配数 的格式，例如 "1/17"。

测试关键词

以下是建议测试的关键词：

  • 搜索 - 在整个页面中出现多次
  • 功能 - 验证中文词语搜索
  • eleBrowser - 测试品牌名称
  • 演示 - 验证特定词汇

搜索特性

新版搜索功能具有以下特点：

  1. 现代化的UI设计，类似您提供的参考图片
  2. 清晰的计数显示格式（如 3/25）
  3. 垂直排列的导航按钮
  4. 实时更新的搜索结果统计
  5. 响应式的视觉反馈

使用指南

操作步骤：

  1. 按下 Ctrl+F 打开搜索面板
  2. 在输入框中输入要查找的文本
  3. 观察右上角显示的匹配计数（如 1/17）
  4. 使用 ▲ ▼ 按钮在匹配项之间导航
  5. 按 Esc 键或 × 按钮关闭搜索面板

技术实现

搜索功能基于 Electron 的 findInPage API 实现，支持：

  • 实时文本匹配
  • 正向和反向搜索
  • 高亮显示匹配项
  • 精确的计数统计
