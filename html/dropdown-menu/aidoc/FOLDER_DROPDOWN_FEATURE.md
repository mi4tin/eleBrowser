# 书签栏文件夹下拉菜单功能

## 功能概述
为书签栏中的文件夹添加了点击显示下拉菜单的功能，用户可以直接在下拉菜单中查看和访问文件夹内的书签和子文件夹。

## 功能特性

### 1. 视觉改进
- **下拉箭头图标**：文件夹项目右侧添加了小箭头（▼），提示用户可以展开
- **激活状态**：当下拉菜单打开时，箭头旋转 180 度，提供视觉反馈
- **美观的下拉菜单**：
  - 白色背景，圆角边框
  - 阴影效果，提升层次感
  - 最大高度 400px，超出可滚动
  - 悬停高亮效果

### 2. 交互逻辑
- **点击文件夹**：显示下拉菜单，展示该文件夹下的所有内容
- **再次点击同一个文件夹**：关闭下拉菜单
- **点击其他文件夹**：切换到新文件夹的下拉菜单
- **点击其他地方**：自动关闭下拉菜单
- **窗口大小改变**：自动关闭下拉菜单

### 3. 下拉菜单内容
- **文件夹标题**：顶部显示文件夹名称和图标
- **分隔线**：标题与内容之间有分隔线
- **子文件夹**：显示📁图标，点击打开书签管理页面
- **书签**：显示自定义 favicon，点击直接打开网址

### 4. 智能处理
- **空文件夹**：不显示下拉菜单
- **递归收集**：自动收集所有子文件夹和书签
- **位置计算**：下拉菜单精确定位到文件夹下方
- **事件冒泡**：阻止事件冒泡，避免冲突

## 技术实现

### HTML 结构
```html
<!-- 下拉菜单容器 -->
<div class="folder-dropdown" id="folderDropdown">
    <div class="folder-dropdown-content" id="folderDropdownContent"></div>
</div>
```

### CSS 关键样式
- `.folder-dropdown`：绝对定位，默认隐藏
- `.folder-dropdown.show`：显示状态
- `.folder-dropdown-item`：下拉菜单项样式
- `.bookmark-bar-item.folder-item::after`：下拉箭头图标

### JavaScript 核心函数
1. **`showFolderDropdown(folderId, folderName, folderElement)`**
   - 查找文件夹数据
   - 递归收集所有书签和子文件夹
   - 动态渲染下拉菜单内容
   - 计算并定位菜单位置

2. **`hideFolderDropdown()`**
   - 隐藏下拉菜单
   - 清除激活状态
   - 重置当前文件夹 ID

3. **`collectFolderBookmarks(folder)`**
   - 递归收集文件夹内所有内容
   - 包括子文件夹和书签

## 使用示例

### 默认书签数据结构
```
生活 (文件夹)
├── 美食 (空文件夹)
└── 购物 (文件夹)
    └── 淘宝 (书签)

世界消息 (文件夹)
├── 彭博社 (文件夹)
│   ├── 特朗普：将于明年 4 月访华 (书签)
│   └── 彭博社放风救市... (书签)
└── 路透社 (空文件夹)
```

### 操作流程
1. 点击"生活"文件夹 → 显示下拉菜单
2. 菜单显示：
   - 标题：📁 生活
   - 📁 美食
   - 📁 购物
   - 🛒 淘宝
3. 点击"淘宝" → 在新标签页打开淘宝
4. 点击空白处 → 关闭下拉菜单

## 优势

### 用户体验
- ✅ **快速访问**：无需跳转到书签管理页面
- ✅ **直观展示**：直接看到文件夹内容

### 技术优势
- ✅ **轻量级**：纯前端实现，无需额外依赖
- ✅ **高性能**：按需渲染，动态生成

## 注意事项

1. **空文件夹处理**：如果文件夹为空，不会显示下拉菜单
2. **位置计算**：下拉菜单会根据文件夹位置自动调整
3. **事件处理**：使用事件委托和冒泡控制，避免冲突
4. **响应式**：窗口大小改变时自动关闭菜单
