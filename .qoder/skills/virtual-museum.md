# Virtual Museum Skill

虚拟博物馆技能。

## 功能说明
- 在线博物馆参观
- 文物和展品介绍
- 历史文化学习

## 使用方法
在聊天中输入：
- `/museum` - 打开虚拟博物馆
- `/exhibit 展览名` - 参观特定展览
- `/artifact 文物名` - 查看文物详情
- `/virtual-tour` - 虚拟导览

## 博物馆功能
- `/collections museum` - 馆藏浏览
- `/historical-periods` - 历史时期
- `/cultural-heritage` - 文化遗产
- `/educational-programs` - 教育项目

## 互动体验
- `/guided-tour` - 导览服务
- `/augmented-reality` - 增强现实展示
- `/interactive-exhibits` - 互动展品
- `/multimedia-content` - 多媒体内容

## 实现原理
通过3D建模和虚拟现实技术创建沉浸式的博物馆参观体验。
