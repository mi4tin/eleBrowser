# Weather Forecast Skill

天气预报技能。

## 功能说明
- 实时天气信息查询
- 多地区天气预报
- 天气预警通知

## 使用方法
在聊天中输入：
- `/weather` - 查看当前天气
- `/weather 北京` - 查询指定城市天气
- `/forecast` - 未来天气预报
- `/weather-alerts` - 天气预警信息

## 天气详情
- `/temperature` - 温度信息
- `/humidity` - 湿度信息
- `/wind` - 风力风向
- `/air-quality` - 空气质量指数

## 高级功能
- `/weather-map` - 天气地图
- `/hourly-forecast` - 小时预报
- `/weather-history` - 历史天气
- `/travel-weather` - 出行天气建议

## 实现原理
集成天气API服务，提供准确的实时天气信息和预报数据。
