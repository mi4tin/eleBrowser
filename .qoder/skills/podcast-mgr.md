# Podcast Manager Skill

播客管理技能。

## 功能说明
- 播客订阅和管理
- 智能推荐
- 离线收听

## 使用方法
在聊天中输入：
- `/podcasts` - 打开播客管理器
- `/subscribe-podcast 名称` - 订阅播客
- `/episode 标题` - 播放指定节目
- `/discover` - 发现新播客

## 播客功能
- `/library podcasts` - 播客库
- `/queue` - 播放队列
- `/downloads podcasts` - 离线下载
- `/subscriptions podcasts` - 订阅管理

## 智能功能
- `/recommendations` - 个性化推荐
- `/categories` - 按类别浏览
- `/search-podcasts` - 搜索播客
- `/listening-history` - 收听历史

## 实现原理
通过播客RSS订阅和音频播放技术提供完整的播客收听体验。
