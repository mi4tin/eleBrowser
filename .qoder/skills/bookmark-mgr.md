# Bookmark Manager Skill

高级书签管理技能。

## 功能说明
- 高级书签组织和管理功能
- 支持文件夹、标签、分类管理
- 批量操作和智能整理

## 使用方法
在聊天中输入：
- `/bookmarks advanced` - 打开高级书签管理
- `/folder 新建文件夹` - 创建书签文件夹
- `/tag 工作` - 为当前页面添加标签
- `/organize` - 自动整理书签

## 批量操作
- `/select-all` - 选择所有书签
- `/move-selected folder` - 移动选中书签
- `/delete-selected` - 删除选中书签
- `/export-bookmarks` - 导出书签为HTML

## 智能功能
- `/find-duplicates` - 查找重复书签
- `/sort-by date` - 按日期排序书签
- `/backup-bookmarks` - 备份书签数据
- `/sync-bookmarks` - 同步书签到云端

## 实现原理
通过增强的书签数据结构和管理接口提供高级书签操作功能。
