# Home Automation Skill

家居自动化技能。

## 功能说明
- 智能家居控制
- 场景模式设置
- 能耗监控

## 使用方法
在聊天中输入：
- `/home` - 打开家居控制
- `/lights on` - 控制灯光
- `/temperature 22度` - 调节温度
- `/security` - 安防监控

## 场景模式
- `/scene movie` - 电影模式
- `/scene sleep` - 睡眠模式
- `/scene party` - 聚会模式
- `/scene away` - 离家模式

## 智能功能
- `/voice-control` - 语音控制
- `/schedule-tasks` - 定时任务
- `/energy-monitor` - 能耗监控
- `/maintenance-alerts` - 维护提醒

## 实现原理
通过IoT协议和智能家居平台集成实现家庭设备的智能化控制。
