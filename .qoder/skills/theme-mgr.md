# Theme Manager Skill

主题和外观管理技能。

## 功能说明
- 管理浏览器主题和外观
- 切换深色/浅色模式
- 自定义界面颜色和样式

## 使用方法
在聊天中输入：
- `/theme` - 打开主题设置
- `/dark` - 切换到深色主题
- `/light` - 切换到浅色主题
- `/themes` - 显示可用主题列表

## 主题操作
- `/import-theme file` - 导入自定义主题
- `/export-theme` - 导出当前主题
- `/reset-theme` - 重置为主题默认设置

## 外观定制
- `/font-size 14` - 调整字体大小
- `/zoom 120` - 设置页面缩放比例
- `/layout compact` - 切换紧凑布局

## 实现原理
通过修改CSS变量和应用配置来动态改变界面外观和主题样式。
