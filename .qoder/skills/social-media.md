# Social Media Manager Skill

社交媒体管理技能。

## 功能说明
- 管理多个社交媒体账户
- 统一发布和监控
- 社交数据分析

## 使用方法
在聊天中输入：
- `/social` - 打开社交媒体管理器
- `/post 内容` - 发布社交媒体内容
- `/schedule-post 时间 内容` - 定时发布
- `/social-analytics` - 社交媒体分析

## 平台支持
- `/twitter` - Twitter管理
- `/facebook` - Facebook管理
- `/instagram` - Instagram管理
- `/linkedin` - LinkedIn管理

## 内容管理
- `/content-calendar` - 内容日历
- `/engagement-stats` - 互动统计
- `/follower-growth` - 粉丝增长分析
- `/hashtag-research` - 标签研究

## 实现原理
通过社交媒体API集成实现统一的内容管理和数据分析功能。
