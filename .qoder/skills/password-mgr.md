# Password Manager Skill

密码管理技能。

## 功能说明
- 管理网站登录密码
- 自动填充表单
- 安全存储和加密

## 使用方法
在聊天中输入：
- `/passwords` - 打开密码管理器
- `/save-password` - 保存当前网站密码
- `/fill-form` - 自动填充登录表单
- `/generate-password` - 生成安全密码

## 密码操作
- `/password-strength` - 检查密码强度
- `/change-master-password` - 更改主密码
- `/export-passwords` - 导出加密密码库
- `/import-passwords file` - 导入密码库

## 安全功能
- `/lock-passwords` - 锁定密码库
- `/unlock-passwords` - 解锁密码库
- `/clear-passwords` - 清空密码数据
- `/two-factor on` - 启用双因素认证

## 实现原理
通过加密存储和表单自动填充技术安全地管理用户密码信息。
