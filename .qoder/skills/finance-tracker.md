# Finance Tracker Skill

财务追踪技能。

## 功能说明
- 个人财务管理
- 投资组合跟踪
- 预算和支出管理

## 使用方法
在聊天中输入：
- `/finance` - 打开财务管理器
- `/budget` - 预算管理
- `/expenses` - 支出记录
- `/investments` - 投资组合

## 财务功能
- `/income` - 收入记录
- `/net-worth` - 净资产计算
- `/spending-analysis` - 支出分析
- `/financial-goals` - 财务目标

## 投资追踪
- `/stock-price AAPL` - 查询股票价格
- `/portfolio-value` - 投资组合价值
- `/dividend-tracker` - 股息追踪
- `/market-news` - 市场新闻

## 实现原理
通过金融API和数据可视化技术提供全面的个人财务管理解决方案。
