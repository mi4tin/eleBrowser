# AI Assistant Skill

AI助手集成技能。

## 功能说明
- 集成AI助手功能
- 智能问答和建议
- 内容理解和生成

## 使用方法
在聊天中输入：
- `/ai` - 启动AI助手
- `/ask 问题` - 向AI提问
- `/summarize` - 总结当前页面内容
- `/explain` - 解释选中内容

## AI功能
- `/translate-ai` - AI翻译
- `/rewrite` - AI重写文本
- `/generate-content` - AI生成内容
- `/fact-check` - AI事实核查

## 学习功能
- `/learn-page` - 让AI学习页面内容
- `/remember` - 让AI记住重要信息
- `/forget` - 让AI忘记指定信息
- `/knowledge-base` - 管理AI知识库

## 实现原理
集成大型语言模型API，提供智能对话和内容处理能力。
