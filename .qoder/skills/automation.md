# Automation Skill

浏览器自动化技能。

## 功能说明
- 自动化浏览任务
- 脚本录制和回放
- 定时任务执行

## 使用方法
在聊天中输入：
- `/automate` - 开始录制自动化脚本
- `/stop-record` - 停止录制
- `/play-script script-name` - 回放脚本
- `/schedule-task time script` - 定时执行任务

## 脚本管理
- `/scripts` - 显示脚本列表
- `/edit-script script-name` - 编辑脚本
- `/delete-script script-name` - 删除脚本
- `/export-script script-name` - 导出脚本

## 自动化操作
- `/auto-login` - 自动登录网站
- `/auto-fill` - 自动填写表单
- `/auto-click` - 自动点击元素
- `/wait-for-element` - 等待元素出现

## 实现原理
通过模拟用户交互和DOM操作实现浏览器任务的自动化执行。
