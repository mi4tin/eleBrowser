# Tab Management Skill

标签页管理技能。

## 功能说明
- 管理多个标签页的操作
- 支持标签页切换、关闭、重新排序
- 提供批量操作功能

## 使用方法
在聊天中输入：
- `/next` - 切换到下一个标签页
- `/prev` - 切换到上一个标签页
- `/close-tab` - 关闭当前标签页
- `/reopen` - 重新打开最近关闭的标签页
- `/tabs` - 显示所有标签页列表

## 高级操作
- `/movetab 2` - 将当前标签页移动到指定位置
- `/duplicate` - 复制当前标签页
- `/pin` - 固定当前标签页
- `/mute` - 静音当前标签页

## 实现原理
通过主进程和渲染进程间的IPC通信管理标签页状态和操作。
