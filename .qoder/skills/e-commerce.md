# E-commerce Assistant Skill

电商购物助手技能。

## 功能说明
- 商品比价和搜索
- 购物车管理
- 优惠信息推送

## 使用方法
在聊天中输入：
- `/shop` - 打开购物助手
- `/compare 商品名` - 商品比价
- `/deals` - 查看优惠信息
- `/cart` - 购物车管理

## 购物功能
- `/wishlist` - 心愿单管理
- `/price-alert 商品` - 价格提醒
- `/order-tracking` - 订单跟踪
- `/coupons` - 优惠券管理

## 智能推荐
- `/recommendations shop` - 购物推荐
- `/trending-products` - 热门商品
- `/personalized-deals` - 个性化优惠
- `/shopping-history` - 购物历史

## 实现原理
通过电商平台API集成和价格监控技术提供智能购物辅助功能。
