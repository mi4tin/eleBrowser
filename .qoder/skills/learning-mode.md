# Learning Mode Skill

学习模式技能。

## 功能说明
- 专注学习环境
- 屏蔽干扰内容
- 学习进度跟踪

## 使用方法
在聊天中输入：
- `/learn` - 启用学习模式
- `/study` - 启用学习模式
- `/focus-mode` - 启用专注模式
- `/exit-learning` - 退出学习模式

## 学习工具
- `/timer 25` - 设置学习计时器
- `/break-timer 5` - 设置休息时间
- `/pomodoro` - 番茄工作法
- `/goals` - 学习目标管理

## 进度跟踪
- `/study-time` - 显示学习时间统计
- `/achievements` - 学习成就
- `/streak` - 连续学习天数
- `/progress-report` - 学习进度报告

## 实现原理
通过内容过滤、时间管理和进度追踪技术创建高效的学习环境。
