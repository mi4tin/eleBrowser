# Job Search Skill

求职搜索技能。

## 功能说明
- 职位搜索和申请
- 简历管理
- 求职进度跟踪

## 使用方法
在聊天中输入：
- `/jobs` - 打开求职搜索器
- `/job-search 开发工程师` - 搜索职位
- `/apply 职位ID` - 申请职位
- `/career-advice` - 求职建议

## 求职管理
- `/resume` - 简历管理
- `/applications` - 申请记录
- `/interview-prep` - 面试准备
- `/salary-research` - 薪资调研

## 职业发展
- `/skills-assessment` - 技能评估
- `/certifications` - 证书管理
- `/networking` - 职业网络
- `/career-path` - 职业规划

## 实现原理
通过招聘网站API和职业发展资源整合提供全方位的求职服务。
