# Reading Mode Skill

阅读模式技能。

## 功能说明
- 为网页启用阅读模式
- 优化文章阅读体验
- 去除广告和干扰元素

## 使用方法
在聊天中输入：
- `/read` - 启用阅读模式
- `/reading` - 启用阅读模式
- `/readability` - 启用阅读模式
- `/exit-read` - 退出阅读模式

## 阅读设置
- `/font serif` - 切换字体类型
- `/fontsize 16` - 调整字体大小
- `/width 800` - 调整阅读宽度
- `/theme sepia` - 切换阅读主题

## 自动检测
- 自动检测文章内容
- 智能提取正文
- 保留重要图片和链接
- 适应不同网站结构

## 实现原理
使用Readability.js库分析网页结构，提取主要内容并应用优化的阅读样式。
