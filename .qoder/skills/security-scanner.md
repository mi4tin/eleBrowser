# Security Scanner Skill

安全扫描技能。

## 功能说明
- 扫描网页安全风险
- 检测恶意软件和钓鱼网站
- 分析网站安全性

## 使用方法
在聊天中输入：
- `/scan` - 扫描当前网站安全性
- `/security-check` - 执行安全检查
- `/phishing-test` - 检测钓鱼网站风险
- `/malware-scan` - 扫描恶意软件

## 安全报告
- `/security-report` - 生成安全报告
- `/ssl-check` - 检查SSL证书
- `/vulnerabilities` - 显示已知漏洞
- `/safe-browsing` - 启用安全浏览模式

## 防护功能
- `/block-malicious` - 阻止恶意网站
- `/privacy-check` - 隐私保护检查
- `/tracker-protection` - 跟踪器防护
- `/secure-connection` - 强制安全连接

## 实现原理
集成安全数据库和实时威胁情报，分析网站安全性和潜在风险。
