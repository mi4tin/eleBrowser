# Language Learning Skill

语言学习技能。

## 功能说明
- 多语言学习
- 词汇记忆和练习
- 发音训练

## 使用方法
在聊天中输入：
- `/language` - 打开语言学习
- `/learn-language 英语` - 学习指定语言
- `/vocabulary` - 词汇练习
- `/pronunciation` - 发音练习

## 学习模式
- `/flashcards` - 闪卡练习
- `/grammar` - 语法学习
- `/conversation` - 对话练习
- `/writing-practice` - 写作练习

## 进度管理
- `/language-level` - 语言水平测试
- `/study-streak` - 学习连续天数
- `/proficiency` - 熟练度追踪
- `/language-goals` - 学习目标

## 实现原理
通过语言学习API和记忆算法提供个性化的语言学习体验。
