# Translation Skill

网页翻译技能。

## 功能说明
- 实时翻译网页内容
- 支持多种语言互译
- 选择性翻译特定内容

## 使用方法
在聊天中输入：
- `/translate` - 翻译当前页面
- `/translate en` - 翻译为英文
- `/translate zh` - 翻译为中文
- `/translate-selection` - 翻译选中文本

## 翻译选项
- `/languages` - 显示支持的语言列表
- `/detect-language` - 自动检测页面语言
- `/translation-mode popup` - 设置翻译显示模式
- `/auto-translate on` - 启用自动翻译

## 高级功能
- `/translate-image` - 翻译图片中的文字
- `/translate-pdf` - 翻译PDF文档
- `/offline-translate` - 使用离线翻译
- `/translation-history` - 查看翻译历史

## 实现原理
集成在线翻译API和本地翻译引擎，提供准确的多语言翻译服务。
