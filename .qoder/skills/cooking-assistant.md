# Cooking Assistant Skill

烹饪助手技能。

## 功能说明
- 智能菜谱推荐
- 烹饪步骤指导
- 厨房技巧分享

## 使用方法
在聊天中输入：
- `/cook` - 打开烹饪助手
- `/recipe-search 麻婆豆腐` - 搜索菜谱
- `/cooking-timer 30分钟` - 设置烹饪计时
- `/kitchen-tips` - 厨房小贴士

## 智能功能
- `/ingredient-substitution` - 食材替代建议
- `/nutritional-analysis` - 营养分析
- `/cooking-difficulty` - 难度评估
- `/meal-planning` - 餐食规划

## 个性化服务
- `/dietary-preferences` - 饮食偏好设置
- `/allergy-alerts` - 过敏提醒
- `/seasonal-cooking` - 应季烹饪
- `/leftover-ideas` - 剩菜创意

## 实现原理
通过菜谱数据库和智能推荐算法提供个性化的烹饪辅助服务。
