# Fitness Coach Skill

健身教练技能。

## 功能说明
- 个性化训练计划
- 健身指导和教程
- 进度追踪和激励

## 使用方法
在聊天中输入：
- `/fitness` - 打开健身教练
- `/workout-plan` - 制定训练计划
- `/exercise 动作名` - 查看动作指导
- `/fitness-goals` - 健身目标设置

## 训练管理
- `/workouts` - 训练记录
- `/progress-photos` - 进度照片
- `/fitness-challenges` - 健身挑战
- `/nutrition-guide` - 营养指导

## 健康监测
- `/calories` - 卡路里计算
- `/bmi-calculator` - BMI计算
- `/body-fat` - 体脂率计算
- `/fitness-assessment` - 健身评估

## 实现原理
通过健身数据库和个性化算法提供专业的健身指导和跟踪服务。
