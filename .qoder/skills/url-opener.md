# URL Opener Skill

智能打开URL的技能。

## 功能说明
- 智能识别和打开各种格式的URL
- 支持相对路径和域名补全
- 自动处理HTTP/HTTPS协议

## 使用方法
在聊天中输入：
- 完整URL：`https://www.example.com`
- 域名：`example.com`
- 相对路径：`/path/to/page`
- 搜索关键词：直接输入要搜索的内容

## 智能处理
- 自动添加https://前缀（如果没有协议）
- 智能判断是否为搜索请求
- 支持本地文件路径
- 处理特殊字符和编码

## 实现原理
通过URL解析和智能判断算法，确定最佳的打开方式并在新标签页中加载。
