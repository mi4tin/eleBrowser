# Travel Planner Skill

旅行规划技能。

## 功能说明
- 旅行计划制定
- 行程安排和预订
- 旅行信息查询

## 使用方法
在聊天中输入：
- `/travel` - 打开旅行规划器
- `/plan-trip 目的地` - 制定旅行计划
- `/flights` - 航班查询
- `/hotels` - 酒店预订

## 行程管理
- `/itinerary` - 行程安排
- `/travel-budget` - 旅行预算
- `/packing-list` - 打包清单
- `/travel-tips` - 旅行建议

## 实时信息
- `/flight-status` - 航班状态
- `/weather-destination` - 目的地天气
- `/currency-converter` - 货币兑换
- `/local-attractions` - 当地景点

## 实现原理
集成旅行服务API和地图服务，提供一站式旅行规划解决方案。
