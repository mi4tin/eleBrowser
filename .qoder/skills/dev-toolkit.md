# Developer Toolkit Skill

开发者工具包技能。

## 功能说明
- 集成开发者常用工具
- 代码编辑和调试
- API测试和文档

## 使用方法
在聊天中输入：
- `/dev` - 打开开发者工具包
- `/code-editor` - 启用代码编辑器
- `/api-tester` - API测试工具
- `/debug-console` - 调试控制台

## 开发工具
- `/snippet-manager` - 代码片段管理
- `/regex-tester` - 正则表达式测试
- `/json-formatter` - JSON格式化工具
- `/color-picker` - 颜色选择器

## 高级功能
- `/local-server` - 启动本地服务器
- `/database-browser` - 数据库浏览器
- `/git-tools` - Git工具集成
- `/deployment` - 部署工具

## 实现原理
集成各种开发者工具和服务，提供一站式的开发环境。
